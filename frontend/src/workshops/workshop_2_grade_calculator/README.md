# Workshop 2 - นิว.grade (Grade Calculator)

โปรแกรมตัดเกรด เปิดดูที่ `/workshop-2` อ้างอิงเอกสาร [VueJsTraining.pdf](../../../../docs/VueJsTraining.pdf) (หน้า workshop2)

## โจทย์

รับค่าคะแนนจาก textfield แล้วกดปุ่มเพื่อแสดงเกรดตามช่วงคะแนน

| เกรด | คะแนน |
| --- | --- |
| A | 80 - 100 |
| B | 70 - 79 |
| C | 60 - 69 |
| D | 50 - 59 |
| F | 0 - 49 |

ถ้ากรอกตัวอักษร หรือตัวเลขที่ไม่อยู่ในช่วง 0 - 100 ต้องมีแจ้งเตือน

## ฟีเจอร์

- ช่องกรอกคะแนน กด **ตัดเกรด** หรือกด Enter ได้
- แสดงเกรดเป็นวงกลมสีตามเกรด พร้อมข้อความ
- ตารางเกณฑ์เกรด ไฮไลต์แถวที่ตรงกับเกรดที่ได้
- แจ้งเตือน 2 ชั้นเมื่อกรอกไม่ถูกต้อง: ข้อความใต้ช่องกรอก + ป๊อปอัป (snackbar)
  - ว่างเปล่า / ตัวอักษร / ติดลบ -> "กรุณากรอกคะแนนเป็นตัวเลขเท่านั้น"
  - เกิน 0 - 100 -> "คะแนนต้องอยู่ในช่วง 0 - 100"
- รองรับทศนิยม เช่น 79.5 ได้เกรด B

## สิ่งที่ได้ฝึก

| หัวข้อ | ตัวอย่างในโค้ด |
| --- | --- |
| `v-model` | ผูกช่องกรอกกับตัวแปร `score` |
| Event `@click`, `@keyup.enter` | ปุ่มตัดเกรด / กด Enter |
| `methods` | `calculate()`, `fail()`, `reset()` |
| `v-if` / `v-for` | แสดงผลลัพธ์เมื่อมีเกรด, วนสร้างแถวเกณฑ์ |
| `computed` | `gradeInfo` หาสีและข้อความของเกรดที่ได้ |
| Component + `props` | `components/GradeScale.vue` |
